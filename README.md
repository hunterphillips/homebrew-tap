# hunterphillips/homebrew-tap

Homebrew casks for my macOS utilities.

```sh
brew install hunterphillips/tap/realign
```

| Cask | What it is |
| --- | --- |
| [realign](https://github.com/hunterphillips/realign) | Menu bar app that puts your windows back where you had them, per display setup. |

Apps are signed with a Developer ID and notarized, so they open without extra steps.
